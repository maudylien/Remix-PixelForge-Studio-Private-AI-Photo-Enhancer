# Direktori Tools / Binary Executable — PixelForge Studio

Folder ini menampung binary executable lokal portabel:

- `realesrgan-ncnn-vulkan.exe` (Engine portabel Real-ESRGAN dengan akselerasi Vulkan GPU)

Executable ini diunduh secara resmi dari rilis GitHub:
https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases

Tidak ada instalasi driver CUDA yang diwajibkan karena implementasi NCNN Vulkan mendukung GPU modern:
- NVIDIA GeForce / Quadro / RTX / GTX
- AMD Radeon / Vega / RDNA
- Intel Arc / Iris Xe / UHD Graphics
